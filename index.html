CAPABILITIES

Built for Modern Developers

Combining the speed of browser applications with the power of native desktop configurations.

Native File System Access

Read and write directories directly on your local device. Uses the native Browser File System Access API with standard fallbacks for Safari/Firefox.

AI Agentic Side-Panel

Interact with your persistent workspace AI agent. Stream responses, execute code modifications directly on files, and sync keys for local Ollama/OpenRouter endpoints.

E2E Encryption Sync

Sync configuration, extensions, and workspace state safely. Zero-knowledge PBKDF2 key derivation and AES-GCM client-side encryption keep keys and data hidden from servers.

Open VSX Extensions

Integrates with the public Open VSX Marketplace directly. Search, install, and custom-manage extension definitions in a dedicated panel.

Monaco Code Editor

Leverage standard code highlighting, layout maps, syntax errors, and smooth scrolling with `@monaco-editor/react` embedded inside the PWA.

Unified Backend Combo

A single hybrid Express + Vite server that manages client delivery, API configuration storage via Quick.DB, and concurrently active dev-environment routines.

import { encryptData, decryptData } from './lib/crypto';

// 7Coder Desktop derives AES-GCM keys locally from master passwords
export async function syncSettings(userId, settingsObject, password) {
  try {
    // 1. Encrypt settings with client password
    const payload = await encryptData(settingsObject, password);
    
    // 2. Post encrypted payload to Quick.DB backend
    await fetch('http://localhost:2469/api/sync', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ userId, data: payload })
    });
    
    console.log('Settings synced securely!');
  } catch (err) {
    console.error('Sync failure:', err);
  }
}

Zero-Knowledge Security Architecture

True Client-Side Encryption

Unlike other Web IDEs that compile, run, or store files on remote cloud infrastructure, 7Coder Desktop runs in a localized environment.

  • Local Encryption Keys: Derived using PBKDF2 with salt parameters. No keys or passwords ever leave your machine.
  • AES-GCM-256 Bit Data: All synchronized settings, UI workspace preferences, and active extensions are packaged, encrypted locally, and stored as unreadable binary envelopes.
  • Quick.DB Storage Node: The backend Express database only operates on encrypted blobs, ensuring that even in case of data node breaches, your environment setup is secure.
